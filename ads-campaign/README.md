# SAGECO EVERGREEN — Digital Advertising Campaign

## Overview
This folder contains the complete ad campaign strategy for SAGECO EVERGREEN real estate platform targeting the Ugandan market.

## Total Budget Recommendations
| Platform | Monthly Budget (UGX) | Monthly Budget (USD) |
|----------|---------------------|---------------------|
| Google Ads | 3,450,000 | ~$900 |
| Facebook/Instagram | 2,550,000 | ~$660 |
| **Total** | **6,000,000** | **~$1,560** |

*Budgets can be adjusted — start with 50% and scale up based on ROAS.*

## Campaign Structure
### Google Ads (4 campaigns)
1. **Property Sales** — Search ads targeting land/property keywords
2. **Broker Registration** — Search ads for agent recruitment
3. **Brand Awareness** — Display/YouTube ads
4. **Free Tools** — Search ads for GPS, valuation, title search

### Facebook/Meta Ads (3 campaigns)
1. **Property Sales** — Carousel + single image conversion ads
2. **Retargeting** — Social proof carousel for website visitors
3. **Brand Awareness** — Video ads for broad reach

## Quick Start Checklist
- [ ] Set up Google Ads account → ads.google.com
- [ ] Set up Google Analytics 4 → analytics.google.com
- [ ] Set up Meta Business Suite → business.facebook.com
- [ ] Create Facebook Pixel
- [ ] Add GTM/GA4/FB Pixel env vars to Vercel
- [ ] Verify site in Google Search Console
- [ ] Verify site in Bing Webmaster Tools
- [ ] Upload keyword negative list to Google Ads
- [ ] Create ad copy from google-ads-copy.md
- [ ] Create ad creative images (1080x1080, 1200x628)
- [ ] Set up conversion tracking
- [ ] Launch campaigns
- [ ] Monitor and optimize weekly

## Target Audience
- **Primary:** Ugandan diaspora investing back home, local professionals 25-55, business owners
- **Secondary:** Real estate brokers, agricultural investors, first-time land buyers
- **Geographic:** Kampala, Wakiso, Mukono, Kyenjojo, Fort Portal, Mbarara, Gulu, Jinja
